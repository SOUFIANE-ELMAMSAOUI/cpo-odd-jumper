# cpo Odd Jumper

## Prérequis
- Python 3
- Librairie Pygame
- Résolution d'écran de 1920x1080

## Comment Jouer
**Lancer le jeu :**
```
python3 main.py
```
**Controls en jeu :**
- q : déplacement vers la gauche
- d : déplacement vers la droite
- space : sauter
- e : interagir avec une entitée
- escape : mettre le jeu en pause durant un niveau
